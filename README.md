# enio-123.github.io

Página de acesso aos apps [IEM](https://enio-123.github.io/IEM/) (Matemática do ENEM) e [IER](https://enio-123.github.io/IER/) (Redação do ENEM). Cada botão "Instalar" abre o app com `?instalar`, que mostra o convite de instalação dentro do próprio app (o navegador só instala um app a partir do endereço dele).

Publicada pelo GitHub Pages a partir da branch `main` (Settings > Pages > Deploy from a branch: `main`, pasta raiz).
